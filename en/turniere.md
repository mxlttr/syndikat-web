Here you will find an overview of all current disc golf tournaments in Germany. The idea for this page came about when we realised that the [official website](https://turniere.discgolf.de) did not have a clear map showing all tournaments. To close this gap, we created an interactive map that provides all the relevant information about disc golf events in Germany. Whether you are an experienced player, a new enthusiast or simply looking for the next tournament near you – this map will help you keep track of all upcoming events. Have fun exploring and planning your next dates!

> Use the layers icon in the top right corner to switch between tournaments from discgolf.de and discgolfmetrix.com.

_The data for this map is loaded live from discgolf.de and discgolfmetrix.com, so please contact the organisers if you have questions about the tournaments._
